# 圣诞贺卡原型（Christmas Card Prototype v0.8）

第三周验证产品：圣诞头像框 A 形态（零上传 · 零账号）的可点原型。

- 在线体验：<https://christmas-card-demo.app.workbuddy.host/?sharecode=AK4DJGZMZJ>
- 打开即用：浏览器打开 `index.html`，无外部 JS 依赖（模板图为本地 `tpl/*.jpg`，共 880KB）
- **🎴 更换卡片点击即生效**：按下立刻换模板+祝福，首页大图与祝福语同步刷新；抽卡弹层只做结果展示（5★ 金光 / 4★ 紫光 / 3★ 蓝光，NEW 标记，保底 10 出 4★+ / 30 出 5★，进度存 localStorage）
- **🎵 圣诞音乐默认播放**：《铃儿响叮当》加载即播（被浏览器拦截时首次点击自动续上），按钮可开关
- **自写祝福输入框在首页**：位于「🖼️ 做成贺卡」按钮上方，写完点「用这句」立即上卡
- **素材库只预览**：左下角「📚 素材库 ▾」展开；点击模板只做库内预览不改动当前卡片；祝福列表可直选
- **做成贺卡**：canvas 合成 750×1000 → 长按保存 / Web Share 一键分享

# 原型交付说明 · 2026-11-19（周四）

**交付物：** `原型.html`（10.1 KB，单文件，手机浏览器直接打开，无需安装任何东西）

**验收线对照（来自产品定义「成功指标」）：**

| 设计验收线 | 原型实现 |
|---|---|
| 首屏到出第一张成品 ≤ 30 秒 | 模板默认选中「雪花夜」、祝福默认选中第一条，**最少 2 次点击出图** |
| 全程零键盘 | 6 条祝福语全部内置预设，无任何输入框 |
| 存相册一步完成 | H5 阶段 = 长按图片保存；小程序版换 `saveImageToPhotosAlbum` 一次授权 |
| 分享到群即出卡片 | H5 用系统分享模拟；正式版 `shareAppMessage` 带缩略图标题（原型内已注明） |

**三个核心交互：**

1. **选模板**：雪花夜 / 红鼻麋鹿 / 圣诞树下，点一下即切换（带选中态）
2. **选祝福语**：6 条预设 chip，点选即换
3. **生成图 + 存相册**：canvas 750×1000 实时合成（非截图、非占位图），出图后长按保存

**原型未覆盖（有意留到正式版）：**

- 账号/上传/键盘：按 A 形态定义永久不做
- 广告位：11-18 用户拍板暂缓，原型不含任何广告元素
- 分享卡片缩略图：小程序专属能力，H5 无法真做
- 模板仅 3 个、装饰用固定坐标，正式版换设计稿切图

**给点毛病的人看的口径：** 只需要回答「你会不会为了发祝福再打开它一次」。
